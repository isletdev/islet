# Trademark policy

"Islet", the Islet corner mark and the islet.dev domain are trademarks of Torsten Labs DOO. The software is free under the AGPL-3.0; the name is not, so that people can tell the official project apart from forks and services built on it.

## You may, without asking

- Use "Islet" to refer to the project, to say your software works with Islet, or to describe how you deploy with it ("built on Islet", "an Islet plugin", "Islet-compatible").
- Fork the code under any other name, and say the fork is "based on Islet".
- Use the name in blog posts, talks, tutorials, books and package names that describe rather than brand ("islet-recipe-wordpress").
- Run Islet for yourself or for clients, and say so.

## Please ask first (hello@islet.dev)

- Naming a product, service, company or domain with "Islet" in it, including hosted "Islet as a service" offerings.
- Using the corner mark or the wordmark as your own logo, or modified versions of them.
- Anything that suggests your work is made, endorsed or supported by the Islet project when it is not.

## Never

- Present a modified build as the official Islet release. Modified builds must change the name shown in the panel and the release channel, and must not use Islet's update signing key.
- Register trademarks or domains containing "Islet" for software or hosting.

This policy follows the spirit of the Model Trademark Guidelines (modeltrademarkguidelines.org). It can change; the version in the repository's main branch is the current one.
