# Code of conduct

Be kind, be specific, assume good intent. Islet is built by a small number of people in their own time, and users come from every level of experience.

- Critique the work, not the person. "This breaks when the volume is missing" beats "this is broken".
- Help beginners with the same care as experts. Many users are running their first server.
- No harassment, discrimination or personal attacks, in issues, pull requests, chat or anywhere the project is discussed.
- Security findings go to `security@islet.dev`, not to a public issue.

Maintainers may edit or remove content and block accounts that ignore this. Questions or reports: `conduct@islet.dev`.
