# Umami analytics

1. **Apps, Catalog, Umami.** Name it `umami`, type the domain (stats.example.com), Let's Encrypt. Postgres is installed inside the stack.
2. Open the domain, log in with `admin` / `umami`, change the password, add your website and copy the tracking snippet.
3. **Backups, New plan** with `volume umami_db` and Islet state, nightly.
